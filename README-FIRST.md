# SahelFlow PC check

1. Click the green **Code** button > **Download ZIP** (or use the link the product owner sent you). Unzip it: right-click > Extract All.
2. Open the unzipped folder, copy ALL its files into a new folder `C:\sf-check` (the two files `sahelflow-pc-check.ps1` and `run-launch-twice.cmd` must stay together).
3. Then follow README.md (English), LISEZMOI-fr.txt (Francais) or README-ar.txt (Arabic) from step 2: restart the PC, wait 2 minutes, double-click `run-launch-twice.cmd`.

The script only reads and measures. It sends nothing anywhere. Read the comment block at the top of `sahelflow-pc-check.ps1` to see exactly what it reads and writes.
